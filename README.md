# PCA 刷题助手 · Professional Cloud Architect

一个纯前端的刷题程序，用于备考 Google Cloud **Professional Cloud Architect** 认证。
题目来自 `Professional Cloud Architect_aizh.pdf`（Examtopics 题库 + AI 中文解析）。

## 快速开始

- **最新版（可持续维护）**：https://pca-quiz.cloudsway-8791.chatgpt.site/
- **Workbuddy 版（第一版）**：https://7975754a86a24e0e819c59b44a0e9658.app.workbuddy.host/
- **登录**：用户名 `admin`，密码 `admin`。
- **安全说明**：这是纯前端静态站点，登录门禁和题库都会下发到浏览器，适合个人刷题入口控制，不适合作为生产级账号认证。若需要真正的账号安全，请接入后端认证服务并更换密码策略。

- **本地版**：直接双击 `index.html` 即可（无需安装、无需联网）。

## 功能

| 功能 | 说明 |
| --- | --- |
| 随机模拟考 | 从全部 359 题中随机抽 100 / 50 / 20 题或全部随机 |
| 按 Topic 练习 | 12 个 Topic 单独练习（Topic 1 综合题库 281 题，其余为案例专项题） |
| 错题重练 | 自动收录错题，答对后自动移出；支持一键清空 |
| 中英对照 | 题目/选项默认英文；答错自动展开**中文解析**；可开关「显示中文翻译」 |
| 选项乱序 | 每次进入题目随机排列选项，并自动同步正确答案映射 |
| 案例背景 | 案例题支持弹窗查看完整案例（英文 + 中文） |
| 题目校对 | 每题右上角「✏️ 纠错」，可修正题干、选项、答案，改动仅存本地 |
| 进度统计 | 累计作答、正确率、错题数存于浏览器 localStorage |

## 数据来源与处理

`data/bank.js` 由 PDF 解析生成，已在本次更新中同步校正后的版本：

- 剔除页脚水印（淘宝/闲鱼/微信等推广行）、剔除 1 道纯图片题（Topic 8 #1，选项为架构图）
- 题干与选项：**英文原文**（去除 "Most Voted" 标记）
- 解析：PDF 内 AI 解析的中文全文
- 多选：按 `(Choose two/three.)` 自动识别，共 36 道多选
- 案例题：Topic 1 #219–234 / #268–270 内嵌的案例文本抽成共享的 `caseStudies`（Altostrat Media / KnightMotives Automotive / EHR Healthcare）

共 **359 题**（单选 323、双选 31、三选 5）。题库校验已确认每道题都有选项、答案字母均存在且无重复答案；Topic 8 #1 因 PDF 中选项为架构图图片而未纳入。

## 使用建议

1. 先按 Topic 逐个过一遍，仔细读中文解析建立知识点映射。
2. 再跑「随机 100 道」模拟考试，控制节奏（真实考试约 2 小时 60 题）。
3. 反复刷「错题重练」，直到错题本清空。

## 注意事项

- 极少数题目的官方答案可能存在争议，程序已保留 PDF 中的社区投票与 AI 解析供参考。
- Topic 9/10（TerramEarth）、Topic 6（Mountkirk Games）等题目的案例正文未包含在本 PDF 内，程序仅提示案例名称。
- 本地改动（错题本 / 纠错）与浏览器绑定，换浏览器或清缓存会丢失。
- 登录状态也保存在浏览器 localStorage 中；点击首页右上角“退出登录”即可清除登录状态。
